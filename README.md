## 📌 Project Overview
This project is my first practical assignment as part of the **Cybersecurity Training Program** at **Networkwalks (Batch BO84)**. 

The objective was to build and configure a virtual cybersecurity testing lab using **Oracle VirtualBox** and **Kali Linux**. This environment provides an isolated network for practicing ethical hacking and penetration testing techniques safely.

---

## 🎯 Project Objectives
- Install and configure **Oracle VirtualBox**.
- Import and set up a **Kali Linux** virtual machine.
- Create and configure a private **NAT Network**.
- Configure and verify Kali Linux network settings.
- Test network connectivity and DNS resolution.
- Create a clean virtual machine **snapshot** for quick recovery.

## ⚙️ Project Implementation

### 1. Installing & Configuring VirtualBox
Installed Oracle VirtualBox to build and manage the virtual machine infrastructure for the cybersecurity environment.

### 2. Importing & Configuring Kali Linux
Imported the Kali Linux VM into VirtualBox and configured its basic hardware specifications and system settings.

### 3. Creating a Private NAT Network
Configured a private **NAT Network** within VirtualBox. This allows virtual machines to communicate securely with each other while maintaining external network access.

### 4. Configuring & Verifying Network Settings
Configured the Kali Linux network adapter and verified local network interfaces to ensure proper connection to the NAT Network.

### 5. Testing Network Connectivity & DNS
Executed network tests and DNS resolution checks to confirm full internet connectivity and correct routing.

### 6. Creating a Virtual Machine Snapshot
Created a clean snapshot of the fully configured Kali Linux environment, providing a restore point to reset state after testing activities.
